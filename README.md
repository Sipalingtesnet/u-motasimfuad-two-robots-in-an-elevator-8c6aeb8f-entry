**Line:** "Do you come here often? My small-talk subroutine made me ask, but your charge port says every night, so I'll be facing the doors now."

Setup: one robot runs a freshly downloaded small-talk subroutine on a stranger mid-ride,
carries the script out loud, and lets a sensor reading do the talking for it.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
